Sunset County — a GTA VI-inspired open-world web game. Free roam, missions 1–3, combat, police, traffic, and after-hours play: two post-story missions, a ten-gate timed rally with medals and saved records, a landmark photography challenge, and a vehicle workshop with persistent upgrades. No external files or dependencies.

## Run it

```sh
node serve.ts
```

Serves `game/` on http://127.0.0.1:8080 — open it in a browser and play.
